앱 주소

https://geo-2026.github.io/travel-internship/

가입도, 로그인도, 앱 설치도 필요 없습니다. 링크를 열면 바로 시작합니다. 입력한 내용은 지금 쓰는 기기에만 저장되고 선생님이나 서버로 보내지지 않습니다.

무엇을 하는 앱인가요

여행 계획을 세우고 방문할 곳을 지도에 표시한 다음, 2쪽짜리 PDF 로 내려받아 제출합니다. 화면은 3단계로 되어 있고, 위쪽의 1 여행 정보 2 지도 · 방문지 3 순서 · PDF 를 눌러 오갑니다.

순서대로 따라 하기

1 여행 정보를 입력합니다

여행 명칭 · 학번 · 이름 · 여행할 도시 네 가지를 넣습니다. 네 칸을 다 채워야 다음 → 버튼이 눌립니다.

  • 도시는 목록에서 고르는 것이 가장 빠릅니다. 칸에 도시 이름 일부를 치면 목록이 좁혀집니다.
  • 목록에 없는 도시라면 직접 검색하기 를 누릅니다.
  • 여기서 고른 도시가 방문지 검색의 범위가 됩니다. 도시를 먼저 정해야 2단계 검색이 잘 됩니다.

2 지도에 방문지를 표시합니다

+ 숙소 + 관광 명소 + 현지 맛집 + 엑티비티 버튼으로 원하는 만큼 추가합니다. 이동방법 도 한 번 채워 주세요.

팝업이 열리면 ① 위치 검색 → ② 이름 입력 → ③ 아이콘·색상 고르기 → ④ 가격·설명 순서로 채우고 적용 을 누릅니다.

💡 검색이 안 될 때는 — 현지어로 쳐 보세요

해외 장소는 한글로 소리 나는 대로 쓰면 거의 찾지 못합니다. 인터넷에서 그 장소의 현지 이름이나 영어 이름을 먼저 찾아본 뒤, 그 이름으로 검색하세요.

  • 에펠탑→La Tour Eiffel
  • 오도리공원→大通公園
  • 오사카성→大阪城

국내 여행이라면 한글로 그냥 치면 됩니다(경복궁, 광장시장, 성산일출봉 …).

그래도 안 나오면

팝업 안의 검색 결과가 없나요? 지도에서 직접 위치 지정하기 를 누른 뒤, 지도를 0.6초쯤 꾹 누르면 그 자리가 위치로 정해집니다. 이름은 직접 적으면 됩니다.

이름 칸은 한글로

검색은 현지어로 하더라도, 이름 칸에는 한글로 적습니다. 카드 목록과 제출용 PDF 에 남는 이름이라 읽을 수 있어야 합니다. (예: 오도리 공원, 규카츠 모토무라 시부야점, 도쿄 카트 레이싱 체험)

팝업이 지도를 가릴 때

팝업 제목 줄을 잡고 끌면 팝업이 움직입니다. (제목 옆 ⠿ 끌어서 이동 손잡이가 표시입니다.) 한 번 옮기면 뒤쪽 지도가 밝아지고, 지도를 확대하거나 움직일 수 있습니다. 제자리로 되돌리려면 제목 줄을 두 번 누르세요.

3 순서를 정하고 PDF 로 내려받습니다

  • 목록의 ☰ 를 끌거나 n번째 를 골라 방문 순서를 정합니다.
  • 순서를 바꾸면 지도의 번호와 총 이동 거리가 다시 계산됩니다. 잠깐 기다리면 됩니다.
  • 다 되었으면 적용 · PDF 저장 을 누릅니다.

PDF 는 이 기기의 다운로드 폴더에 저장됩니다. 파일 이름은 travel_internship_학번.pdf 형식입니다. 이 파일을 제출하세요.

꼭 알아 두기

공용 크롬북을 쓴다면, 수업이 끝난 뒤 지워 주세요.

오른쪽 위 설정 → 입력 내용 전체 삭제. 지우지 않으면 다음 시간에 그 기기를 쓰는 친구에게 내 계획이 그대로 보입니다.

기기를 바꿔야 할 때 설정 → 계획 내보내기 (JSON) 로 파일을 저장해 두었다가, 다른 기기에서 계획 불러오기 (JSON) 로 이어서 하면 됩니다.
저장 버튼이 없어요 입력하는 즉시 자동으로 저장됩니다. 창을 닫았다가 다시 열어도 그대로 남아 있습니다.
이동 거리·시간 대중교통을 골라도 도로 기준으로 계산한 근삿값입니다. 실제 지하철·버스 시간과 다릅니다.

잘 안 될 때

이런 증상이렇게 해 보세요
지도가 회색·단색으로만 보인다 Ctrl+Shift+R 로 새로 고쳐 보세요. 그래도 그대로면 지도 위에 뜨는 안내 문구를 선생님께 알려 주세요.
검색해도 결과가 없다 ① 두 글자 이상 입력했는지 ② 현지어·영어 이름으로 바꿔 보기 ③ 그래도 안 되면 지도를 길게 눌러 직접 지정
검색이 갑자기 멈춘다 1분에 20번까지만 검색할 수 있습니다. 1분쯤 뒤에 다시 해 보세요.
지도 글씨가 한글이 아니다 고장이 아닙니다. 그 지역에 한글 이름 정보가 없으면 현지어로 나옵니다.
[다음] 버튼이 눌리지 않는다 1단계의 네 칸(여행 명칭·학번·이름·도시)이 모두 채워졌는지 확인하세요.
PDF 가 안 만들어진다 방문지를 하나 이상 추가했는지 확인하고, 잠시 기다린 뒤 다시 눌러 보세요.
